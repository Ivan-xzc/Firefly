## Taylor公式(Peano余项、 Lagrange余项)

核心思想：用一个 n 次多项式去逼近一个复杂的函数 f(x)。只要函数在某个点附近足够光滑（可导次数够多），这个多项式就能在局部几乎完全复制原函数的走势。

如果函数 f(x) 在点 x0 处有 n 阶导数，那么在 x0 附近，有：

f(x) = f(x0)

f'(x0) * (x - x0) / 1!

f''(x0) * (x - x0)^2 / 2!

...

f^(n)(x0) * (x - x0)^n / n!

o( (x - x0)^n ) Peano余项

f(x) = f(x0)

f'(x0) * (x - x0) / 1!

f''(x0) * (x - x0)^2 / 2!

...

f^(n)(x0) * (x - x0)^n / n!

R_n(x)

其中余项 R_n(x) = f^(n+1)( ξ ) * (x - x0)^(n+1) / (n+1)!
这里 ξ 是介于 x0 和 x 之间的某个数。

麦克劳林公式：

e^x 的展开：1 + x + x^2/2! + x^3/3! + ... + x^n/n! + o(x^n)

sin(x) 的展开：x - x^3/3! + x^5/5! - ... + (-1)^(m) * x^(2m+1)/(2m+1)! + o(x^(2m+2))

cos(x) 的展开：1 - x^2/2! + x^4/4! - ... + (-1)^(m) * x^(2m)/(2m)! + o(x^(2m+1))

ln(1+x) 的展开：x - x^2/2 + x^3/3 - ... + (-1)^(n-1) * x^n/n + o(x^n)

(1+x)^a 的展开：1 + ax + a(a-1)/2! * x^2 + ... + o(x^n) （二项式定理推广）

tan x = x + (1/3)x^3 + o(x^3)

## 海涅定理

一个函数 f(x) 在 x 趋向于 x0 时是否有极限，完全等价于“任何以 x0 为极限的数列，代入函数后得到的数列是否都有同一个极限”。

海涅定理最大的价值不是用来证明极限存在（因为那需要验证所有数列，太麻烦），而是用来快速、漂亮地证明一个函数的极限不存在。

题目：证明当 x 趋向于 0 时，函数 sin(1/x) 的极限不存在。

证明过程：
取第一个数列 xn = 1 除以 (n 乘以 π)。
当 n 趋向于无穷大时，xn 显然趋向于 0。
代入函数：sin(1/xn) = sin(nπ) = 0。所以这个数列的极限是 0。

取第二个数列 yn = 1 除以 (π/2 + 2nπ)。
当 n 趋向于无穷大时，yn 也趋向于 0。
代入函数：sin(1/yn) = sin(π/2 + 2nπ) = 1。所以这个数列的极限是 1。

因为 0 不等于 1，同样是 x 趋向于 0，却得到了两个不同的极限值。
根据海涅定理，原极限 lim sin(1/x) 当 x 趋向于 0 时不存在。

## 导数定义和微分定义

导数描述的是函数在某一点附近瞬时变化率。

几何意义：曲线上该点切线的斜率

微分描述的是：当自变量变化一个微小量 Δx 时，函数值增量的“线性主部”。、

几何意义：用切线上纵坐标的增量（而不是曲线上）来近似代替曲线上的增量。

## 夹逼性和单调有界定理

数列前面有限项的变化不会影响它的收敛性,所以我们可以将“从某一项开始为单调的数列”，看作单调数列
